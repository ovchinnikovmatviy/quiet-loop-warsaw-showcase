# Quiet Loop - Warsaw Cycling App

[English](#english) | [Русский](#русский)

## English

Quiet Loop is a personal iPhone app for planning relaxed cycling routes around Warsaw and recording rides.

- Choose a destination or route distance and plan a cycling route.
- Follow the route with on-screen navigation guidance.
- Record GPS rides and review time, distance, speed, and ride history.
- Check local weather and use the interface in Russian, Polish, or English.

### Privacy

Ride history and settings stay in the app's local database on the iPhone. Route and weather services receive the location data needed to provide their results. The app has no account or cloud ride sync.

This public page contains a project overview only. The source code and device data remain in the private repository.

## Русский

Quiet Loop - личное приложение для iPhone для планирования спокойных веломаршрутов по Варшаве и записи поездок.

- Выбор места или расстояния и построение маршрута.
- Экранные подсказки по маршруту.
- Запись поездок и просмотр времени, расстояния, скорости и истории.
- Погода для текущего местоположения и интерфейс на русском, польском или английском.

### Приватность

История поездок и настройки хранятся в локальной базе приложения на iPhone. Сервисы маршрутов и погоды получают необходимые для работы данные о местоположении. В приложении нет аккаунта и облачной синхронизации поездок.

Эта публичная страница содержит только описание проекта. Исходный код и данные с устройства остаются в закрытом репозитории.
